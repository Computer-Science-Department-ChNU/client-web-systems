# Інженерія клієнтських веб-систем

В даному репозиторії зберігаються всі [презентації](lectures) та [практичні](practice) завдання для освоєння
дисципліни "Інженерія клієнтських веб-систем".

Розробники курсу: Карачевцев А.О., Томюк Г.М. (кафедра Програмного забезпечення комп’ютерних систем)

## Анотація дисципліни (призначення навчальної дисципліни)

Навчальна дисципліна спрямована на вивчення сучасних архітектурних концепцій, шаблонів проєктування та інженерних
підходів до побудови складних клієнтських веб-застосунків. Курс охоплює повний спектр розробки сучасних Single Page
Applications (SPA): від забезпечення строгої типізації за допомогою екосистеми TypeScript до декомпозиції інтерфейсів на
базі компонентно-орієнтованої парадигми. Студенти вивчають внутрішню архітектуру рушіїв реактивності (Virtual DOM,
Diffing, Signals), менеджмент життєвого циклу компонентів, ізоляцію побічних ефектів для запобігання витокам пам'яті, а
також проєктування реактивних форм із декларативною валідацією. Особлива увага приділяється глобальному управлінню
станe, клієнтській маршрутизації зі стратегіями оптимізації бандлу (Code Splitting), а також високорівневим стратегіям
рендерингу (CSR, SSR, SSG, ISR) та механізмам гідратації. Курс детально розкриває концепцію та інженерні стратегії
кешування, завершуючись практиками профілювання продуктивності та безпеки клієнтських фреймворків (XSS, CSRF).

## Мета навчальної дисципліни

Формування комплексних теоретичних знань та стійких практичних навичок, необхідних для проєктування, оптимізації та
розгортання високопродуктивних, безпечних та масштабованих користувацьких інтерфейсів. Роль дисципліни полягає у
якісному переході від імперативного маніпулювання елементами веб-сторінок до декларативного моделювання інтерфейсів як
чистих функцій від стану системи. Курс закладає глибоке інженерне розуміння архітектурних шаблонів клієнтської сторони (MVC, MVVM), вчить балансувати між процесорною вартістю гідратації та бюджетом часу відповіді сервера (TTFB) для
покращення Core Web Vitals. Опанування цієї дисципліни дозволяє випускникам діяти як кваліфіковані Front-end інженери,
здатні самостійно обирати оптимальні стратегії рендерингу під бізнес-вимоги продукту, ефективно управляти асинхронними
процесами у браузері та інтегрувати клієнтську частину з корпоративними Backend-платформами в межах єдиної
ІТ-екосистеми.

## Пререквізити:

- Веб-технології (част.1+2) — технологічний пререквізит: нативний JavaScript ES6+, механізми Event Loop, Fetch API,
  робота з Web Storage та семантична верстка.
- Процес розробки UI дизайну (част.1+2) — візуально-архітектурний пререквізит: Атомарний дизайн Фроста, методологія BEM,
  Figma Variables як основа трирівневих дизайн-токенів, адаптивні сітки.
- Проєктування та рефакторинг програмних систем — архітектурний пререквізит: шаблони проєктування, узагальнення
  Generics, контракти об'єктів для хешування.

## Необхідні знання та вміння для вивчення

Для успішного опанування цієї дисципліни студент перед її початком повинен:

- Знати: синтаксис, замикання, прототипи та асинхронну модель пам'яті нативного JavaScript (ES6+), механізми Event Loop,
  специфікацію Fetch API та протокол WebSockets, правила семантичної верстки HTML5/CSS3.
- Вміти: розробляти інтерактивні клієнт-серверні вебзастосунки на чистому JavaScript, виконувати складні асинхронні
  запити, керувати станом через Web Storage, проводити глибокий дебаг та профайлінг швидкодії через Browser DevTools та
  працювати з Git.
