# React — приклади коду до лекцій

Повні приклади коду, які використовуються або розширюють приклади зі слайдів лекцій 10–15.

Структура:
- 10/ — React basics, JSX, refs
- 11/ — state, reducer, Context, Effects, Custom Hooks
- 12/ — REST API, Repository, CRUD, Error Boundary, Axios
- 13/ — Routing, Nested Routes, Data mode, Protected Routes, Composition
- 14/ — Forms, React 19 Form Actions, Authentication, JWT
- 15/ — Zustand, TanStack Query, Performance, Testing

Приклади спеціально винесені з презентацій, щоб великий код не стискався на слайдах.
Окремі фрагменти є навчальними: умовні API-функції та типи треба адаптувати до конкретного проєкту.
