Інженерія клієнтських веб-систем

Презентації з дисципліни "Інженерія клієнтських веб-систем".

Розробники курсу: Карачевцев А. О., Томюк Г. М. (кафедра Програмного забезпечення комп’ютерних систем)

Лекція 1. Строга типізація у вебі: екосистема мови TypeScript

Лекція 2. Vue.js: Знайомство з фреймворком Vue.js

Лекція 3. Vue.js: Основи роботи з компонентами. Шаблони. Директиви

Лекція 4. Vue.js: Options API vs Composition API. Основи реактивності.

Лекція 5. Vue.js: Основи роботи з компонентами: props, event handling, watchers.

Лекція 6. Vue.js: Основи роботи з компонентами: v-model, forms, slots.

Лекція 7. Vue.js: Маршрутизація у Vue.js.

Лекція 8. Vue.js: Composables, повторне використання логіки зі станом, State manager Pinia.

Лекція 9. Vue.js: Архітектурне проєктування клієнтських вебзастосунків: компонентна модель, шарова організація та модульна структура.

Лекція 10. React: React Fundamentals та ментальна модель React

Лекція 11. React: State, Effects та архітектура компонентів

Лекція 12. React: Робота з API та CRUD-застосунками

Лекція 13. React: Routing та архітектура React-застосунку

Лекція 14. React: Forms, Validation та Authentication

Лекція 15. React: State Management та Production React
